from abc import ABC, abstractmethod is importing from a predefined module in Python called the abc module, which stands for Abstract Base Classes.

# Explanation of the code and the abc module:
The abc module provides the infrastructure for defining abstract base classes (ABCs) in Python. Abstract classes cannot be instantiated directly; they **serve as a blueprint** for other classes. ABCs allow you to define abstract methods, which must be implemented by subclasses.

## What are ABC and abstractmethod?
### ABC:

**ABC** is a base class provided by the **abc module**.
If you want a class to be an abstract class (i.e., a class that cannot be instantiated and must be subclassed), you inherit from ABC.
This allows the class to support the concept of abstract methods.

## abstractmethod:

abstractmethod is a decorator provided by the abc module.
When you decorate a method with **@abstractmethod**, it tells Python that the method is abstract and **must be implemented by any subclass**.

If a subclass does not implement all abstract methods, it will also be considered an abstract class, and you cannot instantiate it.
How It Works in Your Code
Let's break down your code:

```python

from abc import ABC, abstractmethod

class Father(ABC):  # Father is an abstract class

    @abstractmethod  # Abstract method, must be implemented by subclasses
    def disp(self):
        pass
    
    def show(self):  # This is a concrete method (normal method)
        print('Concrete Method')

#my = Father()  # This would raise an error because Father is abstract and cannot be instantiated

class Child(Father):
    def disp(self):  # The abstract method disp must be implemented here
        print("Defining Abstract Method")

# Instantiate the Child class
c = Child()
c.disp()  # Calls the implemented disp method in Child
c.show()  # Calls the show method in Father (inherited from Father)
```
## Explanation of the Code:

## Father Class:

The Father class is an abstract class because it inherits from ABC.
It contains an abstract method disp decorated with @abstractmethod, which means that any subclass of Father must implement this method.
The Father class also has a concrete method show, which is a regular method that can be used by subclasses directly.

## Child Class:

The Child class inherits from Father.
The Child class implements the disp method, which was abstract in Father.
Since Child implements all abstract methods (in this case, only disp), it is no longer an abstract class, and you can create an object of it.
Instantiation:

You cannot create an instance of the Father class directly, as it contains an abstract method.
You can, however, create an instance of Child, because Child has implemented the abstract method disp.
Calling Methods:

c.disp() will print "Defining Abstract Method" because disp is implemented in the Child class.
c.show() will print "Concrete Method", as show() is inherited from the Father class and is a concrete method.
## Key Points:
Abstract Base Classes (ABCs) provide a mechanism for enforcing that certain methods are implemented by subclasses.
You cannot create an instance of an abstract class directly.
The @abstractmethod decorator marks methods that must be implemented by subclasses.
ABC is the base class for defining abstract base classes.
